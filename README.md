# AI Chatbot

A simple command-line chatbot built in Python that uses Google's Gemini AI to answer questions.

## How it works
The program takes your message, sends it to the Gemini API, and prints the AI's reply. It remembers the conversation so you can ask follow-up questions.

## Requirements
- Python 3
- A free Gemini API key from https://aistudio.google.com

## Setup
1. Install the library: `python -m pip install -r requirements.txt`
2. Set your API key (Windows): `set GEMINI_API_KEY=your-key-here`
3. Run the chatbot: `python chatbot.py`

## Example
You: Hello, who are you?
Bot:  Hello! I am a large language model trained by Google.

Type `quit` to exit.
